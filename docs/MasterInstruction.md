# Master Instruction

GitHub `main` is the only source of truth. Every implementation cycle must inspect the current latest `main`, identify the highest-priority unfinished architecture work, make the smallest production-grade surgical change, validate, re-inspect, and commit.

Do not modify the existing `andieDrio/apm-GIBParser` reference repository unless explicitly requested. This repository is a separate mobile/backend project.

Never commit secrets, fabricated intelligence, fake telemetry, Android signing keys, or generated databases. Backend remains authoritative for Group-IB access, normalization, history, classification, assessment, and PDF generation.
